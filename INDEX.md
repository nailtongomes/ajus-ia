# 📑 Índice de Documentação - Dashboard Jurídico

## 🏠 Bem-vindo ao Dashboard de Análise Jurídica!

Este é um projeto completo e funcional de dashboard para análise de processos judiciais trabalhistas, desenvolvido com Next.js, TypeScript e Tailwind CSS.

## 🎯 Roteiros Recomendados

### Para Desenvolvedores
1. 📖 Leia `INICIO_RAPIDO.md`
2. 🚀 Execute `npm install && npm run dev`
3. 📚 Explore `README.md` para entender a arquitetura
4. ✍️ Use `CONTRIBUINDO.md` para adicionar dados
5. ✅ Valide com `VERIFICACAO.md`

### Para Gestores/Executivos
1. 📊 Veja `PROJECT_SUMMARY.md` para entender o que foi entregue
2. 📈 Consulte `ESTATISTICAS.md` para métricas
3. 📚 Leia `README.md` (seção de funcionalidades)

### Para QA/Testes
1. ✅ Use `VERIFICACAO.md` como checklist
2. 🚀 Siga `INICIO_RAPIDO.md` para setup
3. ✍️ Teste adição de dados com `CONTRIBUINDO.md`
